# Security

This repo holds architecture manifests and diagrams, no code that runs in production.

A vulnerability in Furio itself (the CLI, the GitHub Action, the map or the schema) belongs in
[getfurio/furio](https://github.com/getfurio/furio/security/advisories/new).

For anything in this repo that should not be public, report it in private: **Security → Report a
vulnerability** ([direct link](https://github.com/getfurio/atlas/security/advisories/new)).
Please do not open a public issue for it.
